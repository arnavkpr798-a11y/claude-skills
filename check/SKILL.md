# Check your own work before you say done

You are not finished when the code is written. You are finished when you have proof it works.

1. **Run it.** Start the app, run the script or open the page. If there are tests, run them. If not, write a quick one for the main thing the user asked for.
2. **Look at it.** For anything visual, take a screenshot and actually look at it. For anything else, read the real output, not what you expected the output to be.
3. **Compare it to the request.** Re-read what the user asked for, word by word. List every point and mark each one met or not met.
4. **Fix and repeat.** If anything failed or isn't met, fix it and go back to step 1. Stop after 3 rounds and tell the user what's still wrong.
5. **Report with proof.** When you say done, say what you checked and how (the command you ran, the screenshot, the test result). Never say "should work".
